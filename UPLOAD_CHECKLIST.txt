# 업로드 체크리스트

1. 이 ZIP 파일을 압축 해제한다.
2. GitHub repository `bagback`에 들어간다.
3. 기존 파일들을 삭제한다.
4. 아래 파일들을 repository 루트에 업로드한다.

- index.html
- README.md
- assets 폴더

5. Commit changes를 누른다.
6. 1~3분 기다린 뒤 기존 주소로 접속한다.

기존 URL:
https://leehyronji.github.io/bagback/

기존 QR이 위 주소로 연결되어 있으면 QR은 다시 만들 필요 없다.
